📥 جلب منشور من مجموعة فيسبوك

يحمّل كل صور المنشور فقط (بدون قراءة أو معالجة) — يُخزَّنها في pending_facebook/ على GitHub لمعالجتها لاحقًا في جلسة Claude Code عادية. لا تكلفة API هنا.

⚙️ إعداد الاتصال بـ GitHub (مرة واحدة)

نفس التوكن المستخدم في admin.html — لكن هنا يحتاج صلاحية إضافية: Actions: Read and write (بجانب Contents: Read and write). إن كنت أنشأته من admin.html من قبل، عدّل صلاحياته من GitHub → Settings → Developer settings → Fine-grained tokens. يُحفظ في متصفحك أنت فقط ولا يُرسل لأي جهة غير GitHub.

المنشور

لا تعرض هذه الصفحة تقدّم التشغيل مباشرة (قيود GitHub API) — تابع الحالة من صفحة Actions إن أردت، أو فقط انتظر دقيقة وتحقق من pending_facebook/ في المستودع.
